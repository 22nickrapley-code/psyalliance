# PsyAlliance v13 port: ledgers, decisions and release notes

Frozen reference: `implementation-reference/psyalliance-v13/` (commit ceafc8d4, never edited; `node implementation-reference/psyalliance-v13/tools/verify-reference.cjs`).
Original product commit: `c73b008` (the 18 Oct release, pushed to master by Nick). Port branch: `v13-port`.

**Start with `release_runbook.md`** (what is released, the order of work, what was tested, what only Nick can do).

## Architecture (decided 26 Oct 2026, extended 27 Oct)
- `src/workspace/engine.ts`: the reference engine, ported with only data-layer changes (audit: `node scripts/engine-diff.mjs`).
- `public/workspace/*.css`: the 9 reference stylesheets, byte-identical, loaded in the frozen order by `src/app/(workspace)/layout.tsx` (its own root layout, so no older CSS or web fonts leak in). `public/workspace/final.css` loads last: the darker small text (D-04, generated by `e2e/tools/make-contrast-css.py` from the findings sheets) and a few small, listed additions (see `implementation_exceptions.csv`).
- Adapters: `fixture` (reference data, used by tours, demos and visual comparison) and `live` (Supabase, real accounts, through `workspaceCall`).
- Route groups: `(workspace)`, `(site)` and `(account)`, each with its own root layout. The account pages (profile, credentials, continuity, My documents, notifications, settings, demos, groups, admin) sit in the workspace frame (D-01) on the original saving and permission code.

## Tools
- `e2e/tools/parity-capture.cjs` + `e2e/parity/scenarios.cjs`: paired capture, fixed clock, same viewport (`--ref http://localhost:4173 --target http://localhost:3612/dev/workspace` with the preview server).
- `e2e/tools/parity-diff.py OUTDIR`: writes red-pixel diffs and `summary.csv` from a capture (needs numpy and Pillow).
- `e2e/staging/stage.sh`: the disposable local copy of the whole stack (`rebuild` applies every migration to an empty database).
- Tests: `cd e2e && E2E_BASE_URL=http://localhost:3600 npx playwright test --project=staging`. Tests of replaced screens are retired by the triage rows; `E2E_INCLUDE_RETIRED=1` runs them.
